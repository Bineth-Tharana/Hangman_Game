# 🎮 Hangman Game (Python)

A classic console-based Hangman game built with Python. This project demonstrates basic programming logic, including loops, conditional statements, and modular code organization.

---

## 🚀 Features
* **Dynamic Word Selection:** The game randomly selects a word from a pre-defined list.
* **Visual Progress:** Displays the classic Hangman ASCII art stages as the player loses lives.
* **Interactive Gameplay:** Tracks guessed letters and updates the display in real-time.
* **Modular Structure:** Separates game logic, word lists, and visual assets into different Python files.

## 🛠️ Project Structure
The project consists of three main components:
* **main.py:** The core game engine containing the game loop and logic.
* **word_file.py:** A module containing the list of potential words for the game.
* **hangman_stages.py:** A module containing the ASCII art for the different stages.
